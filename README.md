# School Network Design
![Cisco Packet Tracer](https://img.shields.io/badge/Simulation-Cisco_Packet_Tracer-blue)
![Network](https://img.shields.io/badge/Type-Network_Topology-green)

This project allows the simulation and design of a comprehensive network infrastructure for a school/administrative setting using **Cisco Packet Tracer**.

## 📂 Project Contents

The repository contains:
*   **Packet Tracer Files (`.pkt`)**:
    *   `finalproject.pkt`: The complete, final network topology.
    *   `cn_project.pkt`: An earlier version/component of the design.
*   **Documentation**:
    *   `CN PROJECT REPORT.docx`: Detailed report explaining the addressing scheme (subnetting), VLAN configuration, and routing protocols used.
*   **Assets**:
    *   Network diagrams and background images (`ok.png`, `ok2.png`, etc.) used to visualize the layout.

## ⚙️ Requirements

*   **Cisco Packet Tracer**: You need Packet Tracer (preferably version 7.x or 8.x) to open the `.pkt` files.

## 🚀 How to Run

1.  Install Cisco Packet Tracer.
2.  Double-click `finalproject.pkt` to launch the simulation.
3.  You can verify connectivity by:
    *   Pinging between PC nodes in different departments/VLANs.
    *   Checking the router configuration for DHCP and Routing setup.

## 🏗️ Topology Highlights

*   **Star Topology**: Used for end-device connectivity to switches.
*   **VLANs**: Segmentation of the network (e.g., Admin, Faculty, Students).
*   **Routing**: Inter-VLAN routing configured on the main router.
